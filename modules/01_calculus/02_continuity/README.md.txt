# Lesson 02: Continuity & Discontinuity Analysis

### 📘 Mathematical Context
A function is **continuous** if you can draw its graph without lifting your pen. Mathematically, the limit must equal the function value: $\lim_{x \to c} f(x) = f(c)$. 

In this lesson, we visualize **Jump Discontinuity**, which occurs when the left-hand and right-hand limits exist but are not equal.

### 💻 Computational Approach
We use piecewise logic to create a "break" in the data, simulating real-world scenarios where systems experience sudden shifts or state changes.
